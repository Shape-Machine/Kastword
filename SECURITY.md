# Security policy

Kastword is pre-release software and currently has no supported release series.

Please do not disclose vulnerabilities involving microphone access, clipboard contents, command
execution, model loading, or local file access in a public issue. Use GitHub's private
vulnerability reporting feature from the repository's **Security** tab. Include reproduction
steps, affected commit, impact, and any suggested mitigation. Do not include real dictated text,
recordings, credentials, or other private data.

Ordinary bugs without security impact belong in the public issue tracker.
